# Java Study

Java 기본 문법부터 객체지향, 컬렉션, 스레드, I/O, 네트워크, Stream, JDBC까지 학습하며 작성한 예제 코드를 정리한 저장소입니다.

## 학습 내용

| 폴더 | 내용 |
|---|---|
| `00-intro` | Hello World, 출력, 간단한 계산 예제 |
| `01-basics` | 연산자, 조건문, 반복문, 배열, 문자열/참조 타입 |
| `02-oop` | 클래스, 생성자, 메서드, 상속, 인터페이스 |
| `03-exception-nested` | 중첩 클래스, 익명 객체, 예외 처리 |
| `04-java-api` | Object, String, Wrapper, 날짜/시간, 정규식 등 Java API |
| `05-generics-collections` | Generic, List, Set, Map, Properties |
| `06-thread` | Thread 생성, 실행, sleep, join, yield |
| `07-io` | 파일 입출력, Buffer, Files API |
| `08-network` | InetAddress, TCP Client/Server, Echo Server |
| `09-stream` | Stream 필터링, 매핑, 파이프라인, 병렬 스트림 |
| `10-jdbc` | JDBC 연결, CRUD, Transaction, Procedure/Function 호출 |

## 정리 기준

- Eclipse 워크스페이스의 `.metadata`, `.settings`, `bin` 등 IDE/빌드 파일은 제외했습니다.
- 학습 당시 작성한 소스 코드는 가능한 한 원형을 유지했습니다.
- Hadoop MapReduce 실습인 `FindMaxTemperature`는 Java 기초 학습과 성격이 달라 이 저장소에서 제외했습니다.
- JDBC 예제에서 사용했던 `ojdbc8.jar`, `lombok.jar` 같은 외부 JAR 파일은 저장소에 포함하지 않았습니다.

## 실행 환경

- Java / JDK
- Eclipse IDE
- JDBC 예제: Oracle Database

> 이 저장소는 학습 과정에서 작성한 예제 코드와 실습 기록을 정리하기 위한 저장소입니다.
